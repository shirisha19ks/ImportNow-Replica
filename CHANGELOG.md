# Changelog

All notable changes to the ImportNow website project are documented here.

## [1.0.0] - 2026-11-23

### Added
- Responsive landing page for ImportNow.
- Hero section with shipping/logistics visual.
- Navigation bar and page sections for services, industries, and company advantages.
- Import journey/process section.
- Statistics and testimonial sections (illustrative demo content).
- FAQ section.
- Contact form (front-end demo).
- Motion/reveal effects using Framer Motion.
- Icons using Lucide React.
- Back-to-top interaction.

### Built With
- React
- Vite
- JavaScript
- CSS
- Framer Motion
- Lucide React

### Notes
- Contact form currently uses front-end demo behavior and is not connected to a backend.
- Statistics and testimonials are illustrative content.
