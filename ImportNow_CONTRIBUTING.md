# Contributing

Thank you for your interest in improving the ImportNow website replica.

## Getting Started
1. Fork or copy the repository.
2. Install Node.js and npm.
3. Install project dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## Guidelines
- Keep components readable and reusable.
- Use responsive styles for desktop, tablet, and mobile.
- Avoid committing `node_modules`, build output, environment files, or secrets.
- Test changes locally before submitting them.
- Describe the purpose of your changes clearly.

## Reporting Issues
Include steps to reproduce the issue, the expected behavior, and the actual behavior.

## Disclaimer
This is a front-end replica/demo project and is not affiliated with ImportNow.
